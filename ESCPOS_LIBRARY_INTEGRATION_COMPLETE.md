## How It Works

### Image to ESC/POS Conversion Flow:
1. **Capture/Create Image**: HTML → PNG (chromedp) or Direct PNG (visual renderer)
2. **Binarization**: Convert to pure black & white (threshold-based)
3. **Bitmap Conversion**: Convert to bit array format (1 bit per pixel)
   - Width in pixels
   - Height in pixels
   - bytesPerLine = (width + 7) / 8
   - Each byte represents 8 horizontal pixels
4. **ESC/POS Generation**: Use escpos library
   ```go
   e := escpos.New(&buf)
   e.Init()
   e.Raster(width, height, bytesPerLine, imgBW)
   e.FormfeedN(3)
   e.Cut()
   e.End()
   ```

### Bitmap Format:
- Each row is represented by `bytesPerLine` bytes
- Bits are packed left-to-right, MSB first
- Bit value 1 = print black dot
- Bit value 0 = leave white

Example for 576px width:
- bytesPerLine = (576 + 7) / 8 = 72 bytes per line
- Total bitmap size = 72 × height bytes

## Auto-Print Feature
When an order is created:
1. Order is saved to database
2. Print jobs are created automatically (async)
3. 1 bill print job + N label print jobs (one per item)
4. Print worker processes jobs and sends to printer
5. Uses the new escpos library for conversion
